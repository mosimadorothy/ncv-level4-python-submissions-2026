3. Public and private

Protect your data

A shop's till is not open to everyone. The cashier uses approved actions to change the money. In VB.NET, Private keeps data inside the class; Public gives other code approved ways to use it.
Public Class Product
    Private price As Double
    Public Sub SetPrice(p As Double)
        If p >= 0 Then price = p
    End Sub
End Class

Dim mouse As New Product()
mouse.Price = 150 ' ERROR: Price is Private

SetPrice() checks a value before saving it. getPrice() reads it.

4. Constructors

Give an object starting values

A constructor runs when an object is created. In VB.NET, the constructor is named Sub New and has no return type.

Public Class Product
    Private name As String
    Private price As Double
    Public Sub New(n As String, p As Double)
        name = n
        price = p
    End Sub
End Class

Dim mouse As New Product("Wireless Mouse", 150)
The constructor sets name to "Wireless Mouse" and price to 150 for this object.
